How a view stays true to its text

Step through the loop. The text brief holds every fact. The view is a throwaway rendering that you check before you hand it over.

    View format

    Write the brief

    Write the facts in plain text first. This file is the source of truth.

    Lint the brief

    Run the lint script. Fix long sentences, passive voice, and vague words.

    Make one view

    Build the view from the brief. Use the format that fits the shape of the idea.

    Check the view

    Render the view. Look at it. Compare each label and number with the brief.

    Fix in the brief

    If a fact is wrong, change the brief. Then make the view again.

    Hand over both

    Give the reader the view and the brief. The view names the brief path.
