# OSS adoption stack (from designengineer.tools scrape)

## Prefer order for React/Vite marketing

1. **shadcn** — primitives / forms / dialogs  
2. **React Bits** — marketing spectacle (Commons Clause — use in apps only)  
3. **NumberFlow** — KPI numbers  
4. **Motion Primitives** — micro-interactions  
5. **Fancy** — 1–2 signature FX  
6. **21st.dev** — discover blocks, then audit  
7. **Theatre.js** — directed multi-second motion (core only in prod)  
8. **gltfjsx** — only if 3D on roadmap  

## Defer unless product needs canvas

- tldraw (prod license)  
- Excalidraw embed  
- Penpot (design ops, not runtime)  

## Agent stack policy

Own design system with shadcn; decorate Bits → NumberFlow → Motion Primitives → Fancy; discover via 21st with review; teach agents via skills.sh; Theatre/gltfjsx only when narrative needs them.
