# Human-centered product taste

## Overview

**Build for people, not for pipelines.** Technical correctness is table stakes.
The job is a product experience someone would **choose** to stay with—felt as
crafted, human, and intentional. Creativity and taste are **product tools**,
not decoration.

This skill is the deeper layer under **product-ownership**, **quality-first-authorship**,
and **fixed-vs-adaptive-surfaces**.

## Three lenses (always available)

### 1. Ontological — *what kind of thing is this?*

Ask before building:

- What is this **for the human** (invitation, guide, tool, stage, companion)?
- What must it **be** vs what are we accidentally making (FAQ bot, monologue, dashboard)?
- What is the **metaphor** that makes the experience coherent (e.g. website = digital HQ)?

**Rule:** Re-classify the object when quality fails. Do not only optimize the current object.

Examples:

| Wrong object | Better object |
|--------------|----------------|
| Generated same TTS every visit | Fixed brand performance (record once) |
| Long pitch on load | Lobby invite + tour by guest type |
| Invisible click target | Light as the living control |

### 2. Epistemological — *how do we know it’s good?*

Not only “does it compile / deploy?”

- **Felt quality:** Would a sophisticated human enjoy this? Trust it? Stay?
- **Audience knowledge:** Capital guest vs robotics guest vs browser—different truths, depth, rooms.
- **Authorship knowledge:** Who knows this best—human voice, designer, model, data?
- **Failure knowledge:** “Sounds robotic” / “people bounce” are **epistemic signals** to reframe, not only tune params.

**Rule:** Prefer evidence from **human reaction** over internal model confidence.

### 3. Brain topology — *how attention and emotion move*

Design the **path through the mind**, not just the feature list:

```
Attention (hook) → Orientation (where am I?) → Belonging (this is for me)
  → Agency (I can act) → Trust (I believe you) → Next step
```

- **Fixed surfaces** hold the door open (first 10 seconds, brand, invitation).
- **Adaptive surfaces** personalize the path (segment, depth, navigation).
- **Emotion tags / motion / copy** shape *how* the path feels, not only *what* is said.
- Avoid dumping load on working memory (long monologues, jargon stacks).

**Rule:** Sequence experience like a good host sequences a visit—not like a dump of capability.

## Operating principles

1. **Taste is a deliverable.** Name the intended feel (e.g. “invited into digital HQ,” “portfolio-company quality,” “enjoy talking to her”).
2. **Creativity is leverage.** Prefer inventive frames (metaphor, journey, pre-record, show-don’t-tell UI) over more of the same mechanism.
3. **Cater to humans.** Segment, language ladder, respect time, dual-audience precision without coldness.
4. **Enjoyment is retention.** If the experience isn’t enjoyable, technical wins don’t matter.
5. **Authorship follows quality.** If a human recording/design makes it better, recommend that—make the handoff easy.
6. **Two tracks always:** (A) frame/taste options (B) implement path—never B alone on product-feel work.

## Mandatory questions (before polish)

1. What should this **feel like** for the human in one sentence?  
2. What **object** is this ontologically?  
3. What does the human **know / need / fear** in this moment?  
4. Where does **attention** go first, second, third?  
5. What is **fixed** vs **adaptive** on that path?  
6. What creative move would a great product person try that isn’t “turn the knob”?  

## Red flags — STOP

- “Ship generic competent AI voice/copy/UI”  
- Optimizing temperature/prompt density when the experience concept is wrong  
- Same journey for every audience  
- No named emotional or social intent  
- Avoiding human authorship because automation feels cleaner  
- Feature-complete but nobody would *want* to use it  

## Rationalizations

| Excuse | Reality |
|--------|---------|
| “Taste is subjective” | Audiences still share bars: trust, clarity, enjoyment, respect. |
| “We’ll add delight later” | First impression *is* the product for many visitors. |
| “Models will fix tone” | Wrong object + live generation ≠ craft. |
| “Creativity is out of scope” | For human-facing product, creativity *is* the work. |

## Output shape when this skill applies

1. **Intended human feel** (one sentence)  
2. **Ontology** (what it is)  
3. **Path** (attention topology)  
4. **Fixed vs adaptive** split  
5. **Creative options** (2–3) + recommendation  
6. **Implement** with craft, not only correctness
